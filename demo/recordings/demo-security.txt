FleetPermit — security boundaries

[1/6] A lease cannot ask for more tools than the policy allows
      $ kubectl create -f wants-read-secret.yaml   # restart_workload + read_secret
      status: PermissionNotAllowed — tools not permitted by policy sre-remediation: read_secret
      sre-agent       cluster-east  read_secret         DENIED   Access to this tool is forbidden.

[2/6] A lease cannot outlive the policy's maximum
      $ kubectl create -f one-hour.yaml   # maxDuration is 10m
      status: DurationExceedsMaximum — requested duration 1h0m0s exceeds policy maximum 10m0s

[3/6] A lease cannot be widened after approval
      $ kubectl patch toolaccesslease incident-7 --type=json -p '[{"op":"add","path":"/spec/permissions/-","value":{"tool":"read_secret"}}]'
      The ToolAccessLease "incident-7" is invalid: spec: Invalid value: spec is immutable; create a new ToolAccessLease instead
