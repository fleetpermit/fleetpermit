Sources of variance, observed in these runs:

- Each sample includes one host-to-pod probe round trip (see the baseline row), and polling adds up to about 250 ms.
- Occasional activation outliers of a few seconds come from the OCM work agent retrying, with backoff, a status update that conflicted with FleetPermit's spec update on the same ManifestWork (`Operation cannot be fulfilled ... the object has been modified` in the work-agent log).
- Drift recovery is bounded by the klusterlet status sync interval (10 s in the lab): FleetPermit requests an immediate re-apply once OCM reports the object missing.
- Ready status includes OCM status feedback, so it depends on the same status sync interval.
