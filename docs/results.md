Sources of variance in these runs:

- Each sample includes one host-to-pod probe round trip (see the baseline row). Probes repeat every 250 ms, which adds up to 250 ms more. Clusters are polled at the same time, so clusters that change within the same polling round report the same value.
- Drift recovery is bounded by the klusterlet status sync interval (10s in the lab): FleetPermit requests an immediate re-apply once OCM reports the object missing.
- Ready status includes OCM status feedback, so it depends on the same interval.
